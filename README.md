## Projects

| Project | What it does |
| --- | --- |
| [OcuTrace](https://github.com/mark-esparza/ocutrace) | Turns a phone video of the eyes into a nystagmus and saccade recording, with a standardized oculomotor task battery ([live](https://mark-esparza.github.io/ocutrace/)) |
| [SnaCleX](https://github.com/mark-esparza/snaclex) | Browser based structural biology workbench for protein and ligand interaction analysis, pocket ranking, conservation scoring, and exploratory docking |
| [chemtool](https://github.com/mark-esparza/chemtool) | Browser workbench for retrieving and comparing chemical and metabolite records from PubChem and HMDB, with on-device descriptors and reaction balancing |
| [investment-viability-analysis](https://github.com/mark-esparza/investment-viability-analysis) | Turns SEC EDGAR filings and uploaded statements into finance metrics, a live formula Excel workbook, and a written report |
| [finance-hub](https://github.com/mark-esparza/finance-hub-) | AI assistant for personal finance |
